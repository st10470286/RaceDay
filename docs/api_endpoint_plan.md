# Section B: REST API Endpoint Plan

| HTTP Method | Route | Description | Role Required | Request Body | Expected Response |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **POST** | `/api/auth/register` | Registers a new Organiser or Participant user account in the system. | None (Public) | `{"firstName": "Thabo", "lastName": "Mokoena", "email": "runner1@gmail.com", "password": "Password123!", "roleId": 2}` | `201 Created` - Returns created user details (excluding password).<br>`400 Bad Request` - Validation error or email already registered. |
| **POST** | `/api/auth/login` | Authenticates user credentials and issues a JWT token containing user identity and assigned role. | None (Public) | `{"email": "runner1@gmail.com", "password": "Password123!"}` | `200 OK` - Returns JWT bearer token and user role.<br>`401 Unauthorized` - Invalid email or password. |
| **GET** | `/api/users/me` | Retrieves profile details and assigned role of the currently logged-in user. | Any (Logged In) | *None* | `200 OK` - Returns user profile object.<br>`401 Unauthorized` - Token missing or expired. |
| **PUT** | `/api/users/me` | Updates personal details (First Name, Last Name) for the current authenticated user account. | Any (Logged In) | `{"firstName": "Thabo", "lastName": "Mokoena"}` | `200 OK` - Returns updated profile.<br>`400 Bad Request` - Invalid input data. |
| **GET** | `/api/events` | Fetches a list of all active upcoming running, walking, and cycling events. | None (Public) | *None* | `200 OK` - Array of all active events. |
| **GET** | `/api/events/{id}` | Fetches detailed information for a specific event, including its offered categories. | None (Public) | *None* | `200 OK` - Returns full event details.<br>`404 Not Found` - Event ID does not exist. |
| **POST** | `/api/events` | Creates a new sports event. | Organiser | `{"title": "Soweto Marathon 2026", "eventType": "Running", "location": "Soweto", "eventDate": "2026-11-01T06:00:00", "description": "Annual marathon."}` | `201 Created` - Returns newly created event.<br>`403 Forbidden` - User is a Participant.<br>`400 Bad Request` - Validation error. |
| **PUT** | `/api/events/{id}` | Updates details of an existing event owned by the organiser. | Organiser | `{"title": "Soweto Marathon 2026 Updated", "location": "Soweto Stadium", "description": "Updated route details."}` | `200 OK` - Returns updated event.<br>`403 Forbidden` - User does not own event.<br>`404 Not Found` - Event not found. |
| **DELETE** | `/api/events/{id}` | Permanently deletes an event and all associated categories. | Organiser | *None* | `204 No Content` - Event deleted.<br>`403 Forbidden` - Unauthorized role.<br>`404 Not Found` - Event missing. |
| **GET** | `/api/events/{eventId}/categories` | Retrieves all distance and price categories configured for a specified event. | None (Public) | *None* | `200 OK` - Array of event categories.<br>`404 Not Found` - Parent event missing. |
| **POST** | `/api/events/{eventId}/categories` | Adds a new race distance category (e.g., 21.1km Half Marathon) to an event. | Organiser | `{"categoryName": "Half Marathon", "distanceKm": 21.10, "entryFee": 250.00, "maxParticipants": 5000}` | `201 Created` - Returns created category.<br>`400 Bad Request` - Negative distance/fee.<br>`403 Forbidden` - Non-organiser role. |
| **POST** | `/api/enrolments` | Registers the authenticated participant for a specific event category. | Participant | `{"categoryId": 1}` | `201 Created` - Confirmation of enrolment and payment status.<br>`409 Conflict` - Already registered for this category.<br>`403 Forbidden` - Organiser cannot enter races. |
| **GET** | `/api/enrolments/my-enrolments` | Fetches a full list of race registrations for the currently logged-in participant. | Participant | *None* | `200 OK` - Array of participant enrolments.<br>`401 Unauthorized` - Token missing. |
| **GET** | `/api/enrolments/organiser/all` | Allows organisers to view all participant registrations across events they created. | Organiser | *None* | `200 OK` - Array of participant enrolments.<br>`403 Forbidden` - Participant denied access. |
| **POST** | `/api/results` | Records official finish time and placements for an enrolled participant upon event completion. | Organiser | `{"enrolmentId": 1, "finishTime": "03:15:42", "overallPosition": 142, "categoryPosition": 38, "status": "Finished"}` | `201 Created` - Result recorded successfully.<br>`409 Conflict` - Result already recorded for enrolment.<br>`403 Forbidden` - Participant denied. |
| **GET** | `/api/results/my-results` | Fetches official finish times and position rankings for the logged-in participant. | Participant | *None* | `200 OK` - Array of official race result records. |
